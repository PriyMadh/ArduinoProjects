I used an ultrasonic sensor attached to a servo motor, mounted at the front of the car, a gyroscope, an L298N motor driver, and 4 DC motors to build and program an obstacle-avoidance miniature car. It worked by finding the distances to objects in front of it from left to right (0 and 180 degrees, considering 90 degrees is dead ahead), and then comparing those values to choose the direction where the object in front of it was farthest away. I then integrated the gyro to make the turns more precise and based on angular displacement.

The greatest challenges I faced during this project were making sure I was translating between the reference of the ultrasonic plane of reference and the actual car with respect to the ground. Also, because of bias in the gyro and integration that made the bias compound heavily, leading to gyro drift, I needed to write a program that would estimate the bias so that I could remove it from the readings before integrating. I also had to find ways, such as not considering motions under a certain threshold, that would allow me to distinguish code from the real readings within the main code.
